# Música na Educação Infantil

Material de apoio para aulas de música com crianças de 2 a 5 anos.

## Estrutura

- `planejamento/sequencia_didatica.md`: 8 aulas com objetivos, materiais, desenvolvimento e avaliação, além de repertório sugerido.
- `jogos/index.html`: menu dos jogos. Abra no navegador (Chrome ou Edge) e use em projeção ou tablet.
  - `alto_baixo.html`: agudo ou grave (Aula 2).
  - `siga_ritmo.html`: repetir sequências de cores e sons (Aula 3).
  - `instrumentos.html`: jogo da memória com sons de instrumentos (Aula 5).
  - `estilo.css`: visual compartilhado pelos jogos.
- Referências (PDFs):
  - `568549451-Ensinando-Musica-Musicalmente-Keith-Swanwick.pdf`: lido parcialmente (apresentação, sumário e cap. 3, princípios de educação musical). Base da seção "Fundamentação" do planejamento. É uma digitalização de imagem, sem texto pesquisável.
  - `844599633-Musica-na-educacao-infantil-Teca-de-Brito.pdf`: ainda não lido. Digitalização de imagem, sem texto pesquisável.
  - `865840309-Estudos-de-Psicopedagogia-Musical.pdf`: contém apenas a ficha catalográfica da biblioteca (UFRN), não o livro. Para o conteúdo, é preciso o arquivo completo.

## Como usar os jogos

Os sons são gerados no próprio navegador (Web Audio), sem arquivos externos. Funciona offline. Em alguns navegadores o som só começa após o primeiro toque na tela.
